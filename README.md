# 📋 StudyFlow — Student Task Manager

A minimal, elegant, and distraction-free task management web application designed specifically for students. Built with a soothing **Sage & Cream** aesthetic, StudyFlow helps you organize coursework, assignments, exams, and personal study goals with clarity.

🌐 **Live Demo:** [https://mahnoorimranawan22.github.io/student-task-manager/](https://mahnoorimranawan22.github.io/student-task-manager/)

---

## ✨ Features

- **📊 Comprehensive Dashboard**
  - **Dynamic Donut Progress Ring**: Visual completion percentage tracking in real time.
  - **Category Breakdown**: Track tasks across Homework, Assignments, Exams, and Personal tasks.
  - **Priority Breakdown**: High, Medium, and Low workload distribution.
  - **Upcoming & Overdue Trackers**: Quick-glance alerts for items due this week or overdue.

- **📝 Powerful Task Management**
  - Add, edit, and delete tasks with notes, due dates, categories, and priorities.
  - Quick checkbox toggling with smooth strike-through animations.
  - Interactive confirmation modals to prevent accidental deletions.

- **🔍 Search, Filter & Sort**
  - Instant live search by task name or description.
  - Status filters (**All**, **Pending**, **Done**) and Category chips (**Homework**, **Assignment**, **Exam**, **Personal**).
  - Sorting options: Default, Due Date, Priority, and Alphabetical (A–Z).

- **🖐️ Drag-and-Drop Reordering**
  - Reorganize your daily schedule effortlessly with smooth drag-and-drop support.

- **🌓 Sage & Cream Theme (Light & Dark Mode)**
  - Tailored color palette designed to reduce eye strain during late-night study sessions.
  - Persisted user preference with automatic fallback to system color scheme.

- **💾 Local Storage Persistence**
  - All tasks and theme settings are saved locally in your browser—no login or backend required.

- **📱 100% Responsive & Accessible**
  - Mobile-first design optimized for phones, tablets, and wide monitors.
  - Keyboard navigation and accessible ARIA attributes.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic document structure and accessible forms.
- **CSS3**: Custom design system, CSS variables, glassmorphism, flexbox/grid layouts, and micro-animations.
- **JavaScript (ES6+)**: Vanilla client-side logic, SVG donut chart math, event delegation, and localStorage API.

## 🚀 Getting Started

No build tools or package managers required!

### Run Locally

1. Clone or download this repository:
   ```bash
   git clone https://github.com/mahnoorimranawan22/student-task-manager.git
   ```
2. Navigate into the folder:
   ```bash
   cd student-task-manager
   ```
3. Open `index.html` in your favorite web browser (or use VS Code Live Server).

---

## 🌐 Deploying to GitHub Pages

To make the application available online at `https://mahnoorimranawan22.github.io/student-task-manager/`:

1. Go to your repository settings on GitHub: [Settings > Pages](https://github.com/mahnoorimranawan22/student-task-manager/settings/pages).
2. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
3. Under **Branch**, select `main` (or `master`) and folder `/(root)`, then click **Save**.
4. In a few minutes, GitHub will publish your site at:
   ```
   https://mahnoorimranawan22.github.io/student-task-manager/
   ```
